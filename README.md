# 拾光 Luma Album

拾光（Luma Album）是一款连接**本地目录 / 共享文件夹、群晖 Synology Photos 与 WebDAV** 的跨端私人相册，采用 **React + Rust 共享核心 + WebAssembly** 构建，同一套界面与媒体引擎同时运行于 Windows 桌面端、Windows Web 服务、群晖 NAS（x86_64 Docker）与 iStoreOS / 香橙派 5 Plus（ARM64 Docker）。

当前发布版本为 **4.3.3**（v4.3）。

[下载 4.3.3 正式版与升级包 (`web-v4.3.3`)](https://github.com/BinaryEisley/LumaAlbum-Releases/releases/tag/web-v4.3.3) · [Docker Hub 多架构镜像 (`binaryeisley/luma-album:4.2.0`)](https://hub.docker.com/r/binaryeisley/luma-album) · [版本更新说明](web/RELEASE_NOTES.md) · [Docker 首次部署](web/DEPLOYMENT.md) · [网页在线更新指南](web/APP-UPDATES.md)

## 核心特性

- **多相册源统一接入与本地实时监听**：支持本地文件夹 / NAS 挂载目录、群晖 Synology Photos（个人空间与共享空间）及标准 WebDAV，支持侧栏在线编辑相册配置、定时自动扫描与本地目录 `notify` 防抖实时监听。
- **全来源缩略图管线与多视图液态玻璃界面**：本地、SMB、WebDAV 与群晖均支持 640px 自动旋正压缩缩略图（含纯 Rust MP4/MOV 视频时长提取与可选 `ffmpeg` 视频封面帧），内置环形影廊、扇形影廊、虚拟化大库照片墙与「按文件夹」层级视图；采用 macOS 26 风格悬浮可折叠液态玻璃侧栏、顶部悬浮胶囊命令条、移动端底部上滑卡片与 PWA 桌面安装支持，支持 6 套精选主题、6 套氛围套装、三层液态玻璃质感、65 种动态背景与鼠标点击/拖尾特效；目录提取、采样与查看器几何缩放平移由 Rust WASM 加速。
- **全格式媒体、多路 HEIC 压缩转换与大视频流式播放**：支持常见图片、HEIC / TIFF 多路并发快速解码（JPEG 高画质压缩输出，前台原图优先）、iPhone 实况照片（Live Photo）伴生视频，以及 `.mp4`、`.mov`、`.mkv`、`.webm`、`.ogv`、`.3gp` 视频播放；远程群晖与 WebDAV 视频按 32 MiB `Range` 窗口分段拉取（无缓冲流式转发上限 16 GiB），4K 长视频即点即播、随意拖动进度。
- **专业查看器与连续轮播**：查看器内置原图/视频一键下载、桌面端资源管理器定位文件、手动 90° 旋转、可选底部缩略图胶片条、`?` 快捷键浮层、相对路径一键直达所在目录，以及移动端下滑关闭查看器、底部卡片下拉关闭、视频双击左右 ±10 秒手势；支持随机/顺序轮播、多相册轮播方案（Plans）、顶栏快捷续播与损坏项目自动跳过。
- **隐私保险箱、访问控制与在线版本检查**：内置独立密码保护的加密隐私保险箱（Vault）；Web 端配备不泄露照片的中性动态光影登录页（内置 65 种动态背景选板、6 套一键氛围套装与持久化外观记忆），支持密码文件（`LUMA_WEB_PASSWORD_FILE`）或首次启动口令保护，媒体接口统一使用 `Cache-Control: no-store`；Web 与桌面端均支持应用内在线检查 GitHub Release 新版本并自动匹配对应平台产物。

## 快速开始：部署与网页在线升级

### 1. 已有 4.0.x / 4.1.x / 4.2.x / 4.3.x 环境：无损升级至 4.3.3（推荐）

日常版本升级无需重新拉取或导入几百 MB 的 Docker 镜像（`4.3.2` 起支持**一键在线直连更新**，无需经电脑中转）：

- **方式 A（4.3.2 及之后版本推荐：一键在线直连更新）**：打开 **偏好设置 → 应用更新 → 检查更新**，检测到新版本后直接点击 **立即在线更新**，Web 端由服务器直接从 GitHub 拉取并校验 SHA-256 后自动替换重启，Windows 桌面端自动下载校验并重启替换。
- **方式 B（4.3.1 及更早版本首次升级，或离线内网环境：手动上传 `.luma`）**：
  1. 从 [`web-v4.3.3` Release](https://github.com/BinaryEisley/LumaAlbum-Releases/releases/tag/web-v4.3.3) 下载对应平台的 `.luma` 升级包：
     - **群晖（Intel / AMD x86_64）**：`Luma-Web-4.3.3-linux-amd64-v1.luma`
     - **iStoreOS / 香橙派 5 Plus（ARM64）**：`Luma-Web-4.3.3-linux-arm64-v1.luma`
     - **Windows Web（x64）**：`Luma-Web-4.3.3-windows-amd64-v1.luma`
  2. 登录拾光网页，依次打开 **偏好设置 → 应用更新**。
  3. 选择下载好的 `.luma` 文件，点击 **准备更新**，再点击 **替换并更新**。
  4. 服务自动重启后刷新页面即可（可在 `/health` 或设置页确认版本为 `4.3.3`）。

> **数据保留说明**：`4.3.3` 升级包采用 `dataPolicy=preserve`，升级时仅替换应用前后端程序文件，**完整保留** `/data` 下已配置的相册源、索引缓存、收藏、轮播方案与保险箱数据；挂载在 `/photos` 的原始照片目录只读独立，不受应用更新影响。

### 2. 全新 Docker 部署（群晖 / iStoreOS / 香橙派）

首次部署直接从 Docker Hub 拉取 4.2.0 多架构基线镜像（同时包含 `linux/amd64` 与 `linux/arm64`，无需手动下载或 `docker load` `.tar` 归档）：

1. 准备部署目录：放入 `web/compose.nas.yaml`（群晖 x86_64）或 `web/compose.orangepi5plus.yaml`（香橙派 5 Plus / iStoreOS ARM64），按 [Docker 部署指南 (`web/DEPLOYMENT.md`)](web/DEPLOYMENT.md) 配置 `.env` 及 `secrets/web-password.txt`。
2. 直接拉取 `binaryeisley/luma-album:4.2.0` 并启动：
   ```bash
   docker compose -f compose.nas.yaml up -d            # 群晖 x86_64
   docker compose -f compose.orangepi5plus.yaml up -d  # 香橙派 / ARM64
   ```
3. 启动后从 [`web-v4.3.3` Release](https://github.com/BinaryEisley/LumaAlbum-Releases/releases/tag/web-v4.3.3) 下载对应平台的 `.luma` 升级包，在网页端 **偏好设置 → 应用更新** 一键无损升级至 `4.3.3`；升级后即可直接用内置的 **立即在线更新**，后续版本迭代均无需重打或重拉 Docker 镜像。

### 3. Windows 桌面端与本机 Web 服务运行

- **Windows 桌面端**：从 [`web-v4.3.3` Release](https://github.com/BinaryEisley/LumaAlbum-Releases/releases/tag/web-v4.3.3) 下载 `LumaAlbumReact-4.3.3-windows-x64.exe` 直接双击运行（需 Windows 10/11 自带 WebView2 运行时；后续可直接在 **偏好设置 → 应用更新** 点击「立即在线更新」自动替换重启）。
- **Windows 本机 Web 服务**：构建后双击 `web/Start-Web.cmd` 启动内嵌前端的 `web/release/luma-web.exe`，默认监听本机端口，后续同样支持在网页端一键在线更新或上传 `Luma-Web-*-windows-amd64-v1.luma` 自升级。

> **v4 更新协议说明**：v4 采用轻量化无签名 `.luma` 包协议，更新流程无需配置公钥/私钥或额外校验版本与架构代号；在线直连更新额外校验官方 `manifest.json` 的 SHA-256 摘要，更新器保留 `LUMAUPD2` 包头、压缩分片边界与安全相对路径校验，防止异常包写出应用目录。首次从 3.x 升至 4.0.1 基线包时使用 `dataPolicy=fresh` 初始化新数据目录，4.0.2 及后续常规升级默认使用 `dataPolicy=preserve`。

## 4.3.3 更新重点（2026-11-28）

本次更新聚焦**服务端与共享核心安全加固**（保留全部现有相册与保险箱数据；已在 `4.3.2` 的 Web 与桌面端可直接点「立即在线更新」一键升级）：

- **反向代理 `X-Forwarded-For` 防伪造加固**：
  - 将客户端 IP 解析升级为遍历全部同名 `X-Forwarded-For` 头并**从右向左剥离 `LUMA_TRUSTED_PROXIES` 中的可信代理 IP**，取第一个非可信客户端 IP；右侧任意跳出现畸形或非 UTF-8 值时立即 Fail-Closed 回退为底层 TCP 对端地址，彻底封堵通过伪造左侧 `X-Forwarded-For` 绕过单 IP 登录限流或刷爆限流槽位的风险。
- **跨平台 TOCTOU 安全边界文件打开（零二次按路径重开）**：
  - 新增 `confined::open_confined_file` 统一收口本地媒体打开：Linux/Unix 从已打开的 `root` 目录句柄按相对路径逐级 `openat(..., O_NOFOLLOW | O_CLOEXEC)`（末段附加 `O_NONBLOCK` 防止 FIFO 阻塞）原子解析，拒绝中间目录与末段符号链接；Windows 以 `FILE_FLAG_OPEN_REPARSE_POINT` 打开并拒绝重解析点，再直接对已打开句柄调用 `GetFinalPathNameByHandleW` 核验目录边界。
  - 常规媒体流、Live Photo 伴生/嵌入式视频、纯 Rust 缩略图、HEIC/TIFF 解码（Linux 管道 stdin / Windows 句柄内存流）及 Linux `ffmpeg` 视频封面帧（`/proc/self/fd/0`）全链路直接复用该已校验句柄，彻底消除 `canonicalize` 与 `File::open` 之间的竞争窗口。

## 4.3.0（v4.3）更新重点（2026-11-26）

本次 `v4.3` 是一次面向**大库性能、看图手感、移动端原生体验与自动化运维**的全面升级（保留全部现有相册与保险箱数据）：

- **全来源缩略图管线、视频封面帧与纯 Rust 时长解析**：
  - 本地文件夹、SMB 与 WebDAV 普通照片（JPEG / PNG / WebP / GIF / BMP）全面接入 `/thumb/` 缩略图接口，由纯 Rust 图像管线生成 max 640px 自动旋正缩略图（不透明图片压缩为 JPEG q=84，保留真透明通道 PNG），并复用有界内存 LRU 缓存（自动零化、不写明文盘、遵循隐私保险箱锁控），大幅降低照片墙带宽与内存占用。
  - 扫描阶段新增纯 Rust 有界 ISO-BMFF（MP4 / MOV / M4V / 3GP）头解析，无需 `ffmpeg` 即可提取视频时长并显示在照片墙角标与「关于这一刻」信息栏；宿主机存在 `ffmpeg`（或配置 `LUMA_FFMPEG`）时，本地/SMB 视频自动提取 640px 首秒封面帧展示在照片墙与文件夹拼贴封面中，无 `ffmpeg` 时无缝回退至播放图标。
- **HEIC / TIFF 多路并发解码与高画质 JPEG 输出**：
  - 将 HEIC / HEIF / TIFF 解码并发度由单路提升至按 CPU 核数自适应 `2–4` 路（保留前台查看原图优先抢占队列），输出由体积庞大的无损 PNG 切换为高画质 JPEG（缩略图 q=84 / 原图 q=92），传输体积直降 8–15 倍。
- **查看器高频实用能力与移动端原生手势**：
  - 新增原图/视频一键下载（后端支持 `?download=1` RFC 5987 中文文件名响应头，快捷键 `D`）、Windows 桌面端「在资源管理器中显示」、照片手动 90° 顺时针旋转（`R` 键，自动适配缩放与视口居中）、可选底部缩略图胶片条（`G` 键）与 `?` 快捷键说明浮层（同步补齐 `I` 切换信息栏）。
  - 移动端补齐**单指下滑关闭查看器**（带跟手位移与渐隐反馈）、**「关于这一刻」底部卡片下拉手势收起**，以及**视频双击左右 ±10 秒快进/快退**。
- **PWA 支持、登录页全量光影外观面板与前端首屏分包瘦身**：
  - 新增 `manifest.webmanifest`、180/192/512px 应用图标、`apple-touch-icon` 与 `viewport-fit=cover` 全屏元标签，并在 Web 端静态资源白名单放行 `webmanifest`（不缓存私密媒体，完整保持 `Cache-Control: no-store`）。
  - 升级登录页右上角外观控制条为悬浮液态玻璃选板，开放全部 65 种非照片动态背景（支持 5 大分类预渲染缩略图预览、6 套一键氛围套装、随机切换与强度滑块）并实时持久化保存（刷新、重启与退出登录均保留）。
  - 将相册连接、保险箱、轮播方案、登录页、文件夹视图与动态光影背景改为按需懒加载，并拆分 `react` / `motion` / `lucide-react` 供应商 chunk，显著压低主入口首屏 JS 体积。
- **在线检查新版本与本地目录实时监听**：
  - 新增 `/api/release/check`（严格锁定公开分发库 `BinaryEisley/LumaAlbum-Releases` 官方 Releases，优先读取免限流 `manifest.json` 并支持 API 自动回退），Web 端与 Windows 桌面端均可在 **偏好设置 → 应用更新** 一键检查最新版本并自动匹配当前平台下载包，发现新版时侧栏与设置页显示柔和提示圆点。
  - 引入 `notify` 防抖文件系统监听（`watcher.rs`），本地相册新增、修改或删除文件后自动触发增量重扫（可在 **偏好设置 → 读取设置** 随时开关，默认开启；移除/锁保险箱/退出时立即释放目录句柄）。
- **工程与 CI 治理**：

## 4.2.0（v4.2）更新重点（2026-11-25）

本次 `v4.2` 新增**照片墙文件夹层级浏览模式**、全面升级**沉浸式动态光影登录页**与**顶栏续播整合**，并对 Rust 共享核心进行了 8 项并发、性能与安全深度优化（保留全部现有相册与保险箱数据）：

- **照片墙文件夹层级视图（零重扫、全源通用）**：在照片墙工具栏一键切换或在布局下拉中选择「按文件夹」，基于既有 SQLite 目录索引即刻呈现层级视图——多源汇总态先展示相册级封面卡片，进入后展示 1–4 图拼贴的液态折射子文件夹卡片、44px 均衡比例的面包屑导航栏与返回按钮；下方网格仅渲染当前目录直属媒体（保留分页），顶部与文件夹快捷播放支持当前目录及全部子目录递归轮播，且完整联动搜索、媒体类型、收藏、年份/月份与隐私保险箱隔离。
- **沉浸式动态光影登录界面**：登录与首次设置口令界面升级为全屏中性非照片 `AlbumAmbience` 实时光影舞台（绝不泄露任何用户照片），右上角提供场景与主题快捷切换条，搭配 3D 视差光圈徽章、双轨聚焦液态折射表单、密码显隐切换与实时口令长度指示条。

- **Rust 核心并发与性能深度优化**：
  - **缓存锁拆分与非阻塞磁盘访问**：`Cache` 引入共享/独占 `disk_gate` 与独立 `prune_lock`，彻底解除磁盘读取、AES-GCM 加解密、写入与全盘缓存裁剪对全局内存命中的阻塞，并将磁盘命中 `mtime` 更新改为 >10 分钟节流 + 后台线程执行。
  - **消除异步路径 SQLite 同步阻塞与锁中毒风险**：媒体流读取（`transport::media`）、分页与保险箱收藏校验均先释放 `sources` 读锁再通过 `spawn_blocking` 异步读库，并统一替换 `.lock().unwrap()` 防止锁中毒级联崩溃。
  - **大库查询去 `json_extract` 与空收藏跳过**：SQLite `media` 表新增 `motion` 独立列（`user_version=2`，加载旧版 v1 明文/加密快照时自动无缝迁移回填），查询阶段零 JSON 解析，并在空收藏时跳过冗余 `json_each` 查询。
  - **WebDAV 连接池复用与本地动态照片扫描提速**：WebDAV 媒体/目录请求全局复用 `reqwest::Client`（保留 Keep-Alive 与 TLS 复用）；本地/SMB 嵌入式动态照片探测并入 4 线程 `metadata_pool` 并随 `(size, modified)` 增量缓存，伴生 `.mov`/`.mp4` 改为纯内存零 `stat()` 匹配（兼容任意大小写）。
  - **远程动态照片限流清零与细节补齐**：远程动态照片增加 `Semaphore(2)` 并发限制、`Zeroizing` 内存清零与原地 `drain` 裁剪减半峰值内存；`persist_scan_status` 跳过私密保险箱对公开配置的无效回写；桌面端 `atomic_write` 补齐 `sync_all()`，`api_inner` 改用零分配体积估算，`browse()` 补齐非 Windows 根路径支持。

## 4.0.2 更新重点（2026-11-24）

本次更新集中排查并修复了视频播放与自动轮播相关的 5 个问题（完整技术根因与改动记录见 [`docs/fix-2026-11-24-video-playback.md`](docs/fix-2026-11-24-video-playback.md)）：

- **`.MOV`（iPhone 视频 / 实况伴生视频）及 `.mkv` / `.3gp` 播放修复**：在 `X-Content-Type-Options: nosniff` 安全头下，将 HTTP 传输层中的 `video/quicktime` 及视频类 `application/octet-stream` 归一化为浏览器可播放的 `video/mp4`，并补充 `.mkv`、`.3gp`、`.3g2` 识别。
- **群晖 Photos 与 WebDAV 大视频（> 512 MiB）分段流式播放**：远程媒体非 HEAD 请求按 32 MiB `Range` 窗口分段拉取，并将无缓冲按块流式上限提升至 16 GiB，消除大视频 `HTTP 413` 报错。
- **视频错误原因透传与桌面端 CORS 补齐**：视频流返回 HTTP 错误时不再统一误报“浏览器无法解码”，前端主动探测并展示服务端返回的真实原因（如群晖登录过期、文件不存在）；同时补齐 Tauri 桌面端回环接口在 4xx/5xx 响应及 `OPTIONS` 预检上的 CORS 头。
- **手动播放就绪与错误后重试恢复**：修复关闭“自动播放视频”时加载遮罩常驻的问题；视频报错后点击“重试”、底部播放按钮或按空格键均可重新加载媒体流。
- **自动轮播容错跳过**：自动轮播中遇到单个失败媒体自动跳过并提示计数，连续失败达队列长度后才暂停。
