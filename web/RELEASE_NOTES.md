# 拾光 4.3.0

全面升级照片墙缩略图与视频封面管线、HEIC 多路并发 JPEG 输出、查看器实用功能与移动端手势、PWA 桌面安装、前端首屏分包、在线版本检查以及本地目录实时监听（保留现有相册与保险箱数据）。

- **全来源缩略图、视频封面与时长**：本地/SMB/WebDAV 图片全面接入纯 Rust 640px 自动旋正压缩缩略图（内存 LRU 缓存、自动零化、遵循保险箱隔离）；新增纯 Rust MP4/MOV 视频时长解析并显示在照片墙角标与信息栏，宿主机安装 `ffmpeg` 时自动生成本地/SMB 视频封面帧
- **HEIC / TIFF 多路并发与 JPEG 输出**：解码并发度升级为 CPU 自适应 2–4 路（保留前台原图抢占优先），输出由大体积 PNG 切换为高画质 JPEG（缩略图 q=84 / 原图 q=92），传输体积显著降低
- **查看器增强与移动端手势**：新增原图/视频下载（`D`）、桌面端「在资源管理器中显示」、手动 90° 旋转（`R`）、底部可选缩略图胶片条（`G`）、`?` 快捷键浮层，以及移动端下滑关闭查看器、底部卡片下拉关闭、视频双击左右 ±10 秒手势
- **PWA 支持、登录页全量外观持久化与首屏分包瘦身**：新增 `manifest.webmanifest`、180/192/512px PNG 图标与全屏元标签（不缓存私密媒体）；登录页开放全部 65 种非照片动态光影特效（5 分类缩略图选板、6 套一键氛围套装、随机切换与强度调节）并自动持久化保存；懒加载非首屏弹窗与视图并拆分供应商分包，显著减小主入口 JS 体积
- **在线版本检查与本地目录实时监听**：Web 与桌面端均可一键检查 GitHub Release 最新版本并自动匹配当前架构产物；引入 `notify` 防抖文件监听，本地目录文件变动后自动增量重扫（可在读取设置中开关）
- **工程与 CI 优化**：统一 `src-tauri` 直接复用 `luma-album-core`，升级 GitHub Actions 插件至 Node 24 版，并固化响应式布局与 PWA 自动化回归测试
- 本次升级使用 `dataPolicy=preserve`，完整保留现有已配置的相册连接、索引缓存、收藏、轮播方案与保险箱数据

## 4.2.0（历史更新）

照片墙文件夹层级浏览模式、沉浸式动态光影登录页、顶栏续播整合，以及 Rust 共享核心并发与大库性能深度优化（保留现有相册与保险箱数据）。

- 照片墙新增「文件夹层级浏览模式」：工具栏一键切换或在布局下拉选择「按文件夹」，零重扫即刻呈现多源相册卡片与嵌套子目录树，支持 1–4 图封面拼贴、44px 液态玻璃面包屑栏、直属媒体分页与目录级递归轮播，完整联动搜索、媒体类型、收藏、年份/月份与保险箱隔离
- 升级登录与首次设置口令界面：全屏中性非照片动态光影舞台（不泄露任何用户照片），右上角提供场景/主题快捷切换条，搭配 3D 视差光圈徽章、双轨液态折射表单、密码显隐切换与长度指示条
- 精简「我的空间」顶栏布局：移除重复的「添加相册」按钮与工作区整行续播横条，将「接着上次的时光」整合为顶栏右侧液态高光按钮（悬停提示上次文件名）
- Rust 核心缓存锁粒度拆分：引入 `disk_gate` 读写门控与独立 `prune_lock`，磁盘读写、加解密与全盘缓存裁剪不再阻塞全局内存缓存命中，磁盘命中 `mtime` 更新改为节流后台执行
- 消除异步路径 SQLite 同步阻塞与锁中毒风险：媒体流传输、分页与保险箱收藏校验均先释放读锁再异步读库，并统一防中毒错误处理
- 大库查询性能提升：SQLite `media` 表新增 `motion` 独立列（v1 快照加载时自动无缝迁移至 v2），消除查询期每行 `json_extract` 解析，空收藏跳过冗余 `json_each` 查询
- WebDAV 连接池全局复用与本地动态照片提速：WebDAV 请求共享 `reqwest::Client` 保持连接复用；本地/SMB 嵌入式动态照片并入多线程 `metadata_pool` 并随 `(size, modified)` 增量缓存，伴生视频改为纯内存零 `stat()` 匹配
- 远程动态照片增加 `Semaphore(2)` 限流、`Zeroizing` 内存清零与原地裁剪减半内存峰值；修复保险箱扫描误触公开配置回写，补齐桌面端 `atomic_write` 的 `sync_all()` 与非 Windows 根目录浏览支持
- 本次升级使用 `dataPolicy=preserve`，完整保留现有已配置的相册连接、索引缓存、收藏、轮播方案与保险箱数据
